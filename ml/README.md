# Machine Learning & Explainability Module

This module contains ML models and Explainable AI (XAI) pipelines for financial fraud detection.

## Structure (Future Phases)

- `pipelines/`: Training, evaluation, and inference pipelines.
- `models/`: Trained model binaries and serialization wrappers.
- `explainers/`: SHAP tree/kernel explainer implementations and feature attribution logic.
- `features/`: Feature engineering and transformation recipes.
